## 题目
曲线 $f(x) = |x^2 - ax| + \ln x + b$ (其中 $a \neq 1$ ) 在 $x = 1$ 处的切线方程为 $y = 3x$ ，则 $ab =$ [选]

## 选项
A．2
B．4
C．4 或 0
D．0

## 备注

### 我的备注

### AI备注

## 答案
D

## 分析
（无）

## 解析
由题得 $f(1) = |1 - a| + b = 3$ ，若 $a > 1$ ，当 $0 < x < a$ 时， $f(x) = -x^2 + ax + \ln x + b$ ， $f'(x) = -2x + a + \frac{1}{x}$ ，所以 $f'(1) = a - 1 = 3$ ，所以 $\begin{cases} a = 4 \\ b = 0 \end{cases}$ ， $ab = 0$ ；若 $a < 1$ ，当 $x > a$ 时， $f(x) = x^2 - ax + \ln x + b$ ， $f'(x) = 2x - a + \frac{1}{x}$ ，所以 $f'(1) = 3 - a = 3$ ，所以 $\begin{cases} a = 0 \\ b = 2 \end{cases}$ ， $ab = 0$ ，故选 D.
