## 题目
已知事件 $A, B, C, D$ 均为随机事件，则下列结论正确的是 [选]

## 选项
A．若 $P(AB) = 1$ ，则 $A$ 与 $B$ 互斥
B．若 $A, B$ 对立，则 $P(A) + P(B) = 1$
C．若 $A, B$ 互斥，则 $P(A \cup B \mid C) = P(A \mid C) + P(B \mid C)$
D．若 $A, B$ 相互独立，且 $P(A) = \frac{1}{3}, P(B) = \frac{1}{4}$ ，则 $P(A \cup B) = \frac{1}{2}$

## 备注

### 我的备注

### AI备注

## 答案
BCD

## 分析
（无）

## 解析
对于 A，显然错误；对于 B，显然正确；对于 C，由于 $P(A \cup B|C) = \frac{P((A \cup B) \cap C)}{P(C)} = \frac{P(AC \cup BC)}{P(C)} = \frac{P(AC) + P(BC)}{P(C)} = P(A|C) + P(B|C)$ ，C 正确；
对于 D， $P(A \cup B) = P(A) + P(B) - P(A \cap B) = \frac{1}{3} + \frac{1}{4} - \frac{1}{3} \times \frac{1}{4} = \frac{1}{2}$ ，D 正确，故选 BCD.
