## 题目
$\triangle ABC$ 中，角 $A, B, C$ 的对边分别为 $a, b, c, 2c = \sqrt{5}b, C = 2B$ ，则 $\cos A =$ [填].

## 备注

### 我的备注

### AI备注

## 答案
$\frac{7\sqrt{5}}{16}或 \frac{7}{16}\sqrt{5}$

## 分析
利用正弦定理结合二倍角求出 $\cos B$ ，再得到 $\sin B, \cos C, \sin C$ ，借助三角形内角和与两角和余弦公式计算 $\cos A$ .

## 解析
由正弦定理 $\frac{b}{\sin B}=\frac{c}{\sin C}\Longrightarrow\frac{c}{b}=\frac{\sin C}{\sin B}$ ，由 $2c=\sqrt{5}b$ ，得 $\frac{c}{b}=\frac{\sqrt{5}}{2}$ ，所以 $\frac{\sin C}{\sin B}=\frac{\sqrt{5}}{2}$ ，所以

$sin C = \frac {\sqrt {5}}{2} \sin B$

因为 C=2B，所以 $\sin C=\sin 2B=2\sin B\cos B$ ，所以 $\frac{\sqrt{5}}{2}\sin B=2\sin B\cos B$ ，

由 $_{B}$ 是三角形内角， $\sin B \neq 0$ ，故 $2\cos B = \frac{\sqrt{5}}{2}$ ，所以 $\cos B = \frac{\sqrt{5}}{4}$ ，

$\sin B = \sqrt {1 - \cos^ {2} B} = \frac {\sqrt {1 1}}{4}, \quad \sin C = \frac {\sqrt {5}}{2} \sin B = \frac {\sqrt {5 5}}{8}, \quad \cos C = \cos 2 B = 2 \cos^ {2} B - 1 = - \frac {3}{8},$

由 $A = \pi - (B + C)$ ，得 $\cos A = -\cos (B + C) = \sin B \sin C - \cos B \cos C$

$= \frac {\sqrt {1 1}}{4} \times \frac {\sqrt {5 5}}{8} - \frac {\sqrt {5}}{4} \times \left(- \frac {3}{8}\right) = \frac {7 \sqrt {5}}{1 6}.$
