## 题目
已知 $a = 4 \sin \frac{1}{4}$ ， $b = \cos \frac{1}{4}$ ， $c = \frac{15}{16}$ ，则 a, b, c 的大小关系正确的是 [选]

## 选项
A．a > b > c
B．c > b > a
C．b > a > c
D．a > c > b

## 备注

### 我的备注

### AI备注

## 答案
A

## 分析
构造函数 $f(x) = \sin x - x\cos x$ ，导确定单调性，得 $a > b$ ，再构造函数 $g(x) = 1 - x^2 -\cos x$ ，求导确定单调性得到 b > c ，得到答案.

## 解析
设 $f(x) = \sin x - x\cos x$ ， $0 < x < \frac{\pi}{4}$ ，则 $f'(x) = x\sin x$ ，

$0 < x < \frac{\pi}{4}$ ， $\sin x > 0$ ，故 $f'(x) > 0$ ， $f(x)$ 在 $\left(0, \frac{\pi}{4}\right)$ 上单调递增，

故 $f(x) > f(0) = 0$ ，当 $0 < x < \frac{\pi}{4}$ 时， $\sin x > x\cos x$ 恒成立，所以 $\sin \frac{1}{4} > \frac{1}{4}\cos \frac{1}{4}$ ，所以 $a > b$ ；

设 $g(x) = 1 - x^2 -\cos x$ ， $0 <   x <   \frac{\pi}{4}$ ，则 $g^{\prime}(x) = -2x + \sin x$

设 $t(x) = -2x + \sin x, t'(x) = -2 + \cos x$

又 $t^{\prime}(x) = -2 + \cos x < 0$ ，则 $t(x)$ 在 $\left(0,\frac{\pi}{4}\right)$ 上单调递减， $t(x) < t(0) = 0$

故 $g^{\prime}(x) < 0$ ，则函数 $g(x)$ 在 $\left(0, \frac{\pi}{4}\right)$ 上单调递减，即 $g(x) < g(0) = 0$

故当 $0 < x < \frac{\pi}{4}$ 时， $1 - x^{2} < \cos x$ 恒成立，所以 $1 - \frac{1}{16} < \cos \frac{1}{4}$ 恒成立，即 b > c；

综上， $a > b > c$
