## 题目
$\triangle ABC$ 中， $\sin C = 3\sin B$ ，点 $D$ 在 $BC$ 边上， $AD$ 平分 $\angle BAC$ ， $S_{\triangle ABC} = \frac{3}{2}$ ，当 $BC$ 最短时， $\frac{AD}{AC} =$ [选]

## 选项
A．$\frac{\sqrt{5}}{5}$
B．$\frac{2\sqrt{5}}{5}$
C．$\frac{3\sqrt{5}}{5}$
D．$\frac{4\sqrt{5}}{5}$

## 备注

### 我的备注

### AI备注

## 答案
C

## 分析
利用正弦定理可得 $b, c$ 关系，利用三角形面积公式和余弦定理建立 $BC$ 与角 $A$ 的函数式，求导判断单调性可求 $BC$ 最小时 $\cos A$ 的值，最后根据三角形的角平分线性质可求 $\frac{AD}{AC}$

## 解析
$\triangle ABC$ 中， $\sin C = 3\sin B$ ，由正弦定理可得 $c = 3b$ ，代入 $S_{\triangle ABC} = \frac{3}{2} = \frac{1}{2}bc\sin A$ 得

$b ^ {2} \sin A = 1 \Rightarrow b ^ {2} = \frac {1}{\sin A},$

在 $\triangle ABC$ 中根据余弦定理有 $a^2 = b^2 + c^2 - 2bc\cos A$ 代入 $c = 3b$ 得

$a ^ {2} = 1 0 b ^ {2} - 6 b ^ {2} \cos A \Rightarrow a ^ {2} = \frac {1 0}{\sin A} - \frac {6 \cos A}{\sin A} = \frac {1 0 - 6 \cos A}{\sin A}$

即 $BC^{2}=\frac{10-6\cos A}{\sin A}$ .

$\text {令} f (x) = \frac {1 0 - 6 \cos x}{\sin x}, (0 <   x <   \pi), \text {则} f ^ {\prime} (x) = \frac {6 - 1 0 \cos x}{\sin^ {2} x}, (0 <   x <   \pi),$

令 $f'(x)=\frac{6-10\cos x}{\sin^{2}x}=0$ 得 $\cos x_{0}=\frac{3}{5}$ ，即 $x\in(0,x_{0})$ 时 $\cos x>\frac{3}{5}$ ， $f'(x)<0$ ， $f(x)$ 单调递减，

$x \in (x_0, \pi)$ 时 $\cos x < \frac{3}{5}$ , $f'(x) > 0$ , $f(x)$ 单调递增, 所以 $f(x)$ 在 $\cos x_0 = \frac{3}{5}$ 时取得最小值, 即

$\cos A=\frac{3}{5}\Rightarrow\sin A=\frac{4}{5}$ 时 BC 取最小值.

又因为 AD 平分 $\angle BAC$ ，所以 $S_{\triangle ABC} = S_{\triangle ABD} + S_{\triangle ACD}$ 即

$\frac {1}{2} b c \sin A = \frac {1}{2} b \times A D \sin \frac {A}{2} + \frac {1}{2} c \times A D \sin \frac {A}{2} = \frac {1}{2} A D \sin \frac {A}{2} (b + c), \text {代入} c = 3 b \text {化简得}$

$\frac {3}{2} b \cos \frac {A}{2} = A D \Rightarrow \frac {A D}{b} = \frac {3}{2} \cos \frac {A}{2}$

$\text { 结合 } \cos A = \frac {3}{5}, \sin A = \frac {4}{5} \text { 得 } \cos \frac {A}{2} = \sqrt {\frac {1}{2} (1 + \cos A)} = \frac {2 \sqrt {5}}{5}, \text { 所以 } \frac {A D}{b} = \frac {A D}{A C} = \frac {3 \sqrt {5}}{5}$
