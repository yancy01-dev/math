## 题目
已知函数 $f(x) = k\mathrm{e}^{x - 1} - x$ 和 $g(x) = \ln x + \frac{k}{x} - 1$ 各有两个零点。

(1) 求 $k$ 的取值范围；

(2) 若一个函数有且仅有两个零点，则称这两个零点的算术平均数为该函数的"完美点"。设 $\alpha$ 和 $\beta$ 分别为 $f(x)$ 和 $g(x)$ 的"完美点"。

(i) 比较 $\alpha$ 与 $\beta$ 的大小；

(ii) 证明：$f(\beta) < g(\alpha)$。

## 备注

### 我的备注

### AI备注

## 答案
（1）$(0,1)$；（2）(i) $\alpha > \beta$；(ii) 证明详见解析

## 分析
（无）

## 解析
(1) 由 $f(x)=0$，$g(x)=0$，得 $k=xe^{1-x}$，$k=x(1-\ln x)$，则 $f(x)$，$g(x)$ 的零点等价于 $F(x)=xe^{1-x}-k$，$G(x)=x(1-\ln x)-k$ 的零点。$F'(x) = (1-x)e^{1-x}$，$G'(x) = -\ln x$。当 $x > 0$ 时，易知 $F(x)$，$G(x)$ 均在区间 $(0,1)$ 单调递增，且在 $(1, +\infty)$ 单调递减。若 $F(x)$ 有两个零点，则 $\begin{cases}-k<0 \\ 1-k>0\end{cases}$，即 $0<k<1$。当 $0 < k < 1$ 时，$G(1) = 1 - k > 0$，当 $x \to 0$ 时，$G(x) < 0$，且 $G(e) = -k < 0$，故 $G(x)$ 在区间 $(0,1)$ 和 $(1,e)$ 各恰有一个零点。综上，若 $f(x)$，$g(x)$ 各有两个零点，则 $k$ 的取值范围是 $(0,1)$。

(2)(i) 不妨设 $f(x)$ 和 $g(x)$ 的两个零点分别为 $\alpha_{1}$，$\alpha_{2}$ 和 $\beta_{1}$，$\beta_{2}$，则 $\alpha_{1} < 1 < \alpha_{2}$，$\beta_{1} < 1 < \beta_{2}$，且 $\alpha = \frac{\alpha_{1} + \alpha_{2}}{2}$，$\beta = \frac{\beta_{1} + \beta_{2}}{2}$。设 $\varphi(x) = \frac{F(x) - G(x)}{x} = e^{1-x} + \ln x - 1$，则 $\varphi'(x) = -\mathrm{e}^{1-x} + \frac{1}{x} = \frac{1 - x\mathrm{e}^{1-x}}{x}$。设 $t(x)=1-x\mathrm{e}^{1-x}$，则 $t'(x)=(x-1)\mathrm{e}^{1-x}$。当 $0 < x < 1$ 时，$t'(x) < 0$，$t(x)$ 单调递减；当 $x>1$ 时，$t'(x)>0$，$t(x)$ 单调递增。故 $t(x) \geq t(1) = 0$，$\varphi'(x) \geq 0$，$\varphi(x)$ 单调递增。故当 $0 < x < 1$ 时，$\varphi(x) < \varphi(1) = 0$，即 $F(x)<G(x)$；当 $x>1$ 时，$\varphi(x)>\varphi(1)=0$，即 $F(x)>G(x)$。故 $F(\alpha_{1})=G(\beta_{1})=0<G(\alpha_{1})$，$\beta_{1}<\alpha_{1}<1$，同理有 $1<\beta_{2}<\alpha_{2}$。故 $\alpha_{1} + \alpha_{2} > \beta_{1} + \beta_{2}$，即 $\alpha > \beta$。

(ii) 因为 $\beta_{1} < 1$，故 $2 - \beta_{1} > 1$。又 $G(\beta_{2}) - G(2 - \beta_{1}) = G(\beta_{1}) - G(2 - \beta_{1}) = (2 - \beta_{1})\ln(2 - \beta_{1}) - \beta_{1}\ln\beta_{1} + 2\beta_{1} - 2$。设 $h(x)=(2-x)\ln(2-x)-x\ln x+2x-2$，则 $h'(x)=-\ln[x(2-x)]$。当 $0 < x < 1$ 时，$h'(x) > 0$，$h(x)$ 单调递增，故 $h(\beta_{1})<h(1)=0$，即 $G(\beta_{2})<G(2-\beta_{1})$，故 $\beta_{1} + \beta_{2} > 2$。设 $u(x) = f(x) - g(x) = k\mathrm{e}^{x-1} - x - \ln x - \frac{k}{x} + 1$，则 $u(1) = 0$，且 $u'(x) = ke^{x-1} - 1 - \frac{1}{x} +\frac{k}{x^2}$，$u'(1) = 2k - 2 < 0$。当 $x > 1$ 时，$(u'(x))' = ke^{x-1} + \frac{1}{x^2} -\frac{2k}{x^3} > k\left(\mathrm{e}^{x-1} - \frac{1}{x^3}\right) > 0$，$u'(x)$ 单调递增，故当 $x > 1$ 时，$u(x)$ 至多只有一个极值点，且为极小值点。因为 $u(\alpha_{2})=f(\alpha_{2})-g(\alpha_{2})=-g(\alpha_{2})$，且 $g'(x)=\frac{x-k}{x^{2}}$。当 $k<1$，且 $x\in(1,+\infty)$ 时，$g'(x)>0$，$g(x)$ 单调递增，故 $g(\alpha_{2}) > g(\beta_{2}) = 0$，$u(\alpha_{2}) = -g(\alpha_{2}) < 0$。所以当 $x \in (1, \alpha_2)$ 时，$u(x) < 0$，即 $f(x) < g(x)$。又因为 $1 < \beta < \alpha < \alpha_{2}$，故 $f(\beta) < g(\beta) < g(\alpha)$。
