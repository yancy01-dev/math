## 题目
设函数 $f(x) = \log_2 |x|$，若 $a = f\left(\log_{\frac{1}{3}} 2\right)$，$b = f(\log_5 2)$，$c = f(e^{0.2})$，则 $a, b, c$ 的大小为 [选]

## 选项
A. $b < a < c$
B. $c < a < b$
C. $b < c < a$
D. $a < b < c$

## 备注

### 我的备注

### AI备注

## 答案
A

## 分析
（无）

## 解析
因为 $f(-x)=\log_{2}|-x|=\log_{2}|x|=f(x)$，所以 $f(x)$ 为偶函数，所以 $a = f\left(\log_{\frac{1}{3}}2\right) = f(-\log_32) = f(\log_32)$。当 $x > 0$ 时，$f(x) = \log_2 x$ 在 $(0, +\infty)$ 上为增函数。因为 $0 < \log_5 2 < \log_3 2 < 1$，$e^{0.2} > e^0 = 1$，所以 $0 < \log_52 < \log_32 < e^{0.2}$。因为 $f(x)$ 在 $(0,+\infty)$ 上为增函数，所以 $f(\log_{5}2)<f(\log_{3}2)<f(e^{0.2})$，所以 $b < a < c$。故选：A。
