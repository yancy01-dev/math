## 题目
集合 $A = \{x \in N \mid x^2 - 2x - 3 \leq 0\}$，$B = \{x \mid x \leq 2\}$，则 $A \cap B =$ [选]

## 选项
A. $\{-1,0,1,2\}$
B. $\{0,1,2\}$
C. $\{1,2\}$
D. $[-1,2)$

## 备注

### 我的备注

### AI备注

## 答案
B

## 分析
先解一元二次不等式得集合 $A=\{0,1,2,3\}$，再由交集的定义可得结果。

## 解析
由一元二次不等式 $x^{2}-2x-3\leq0$，得 $(x-3)(x+1)\leq0$，所以不等式的解集为 $-1\leq x\leq3$。又因为 $x \in N$，所以 $A = \{0, 1, 2, 3\}$。又因为 $B = \{x \mid x \leq 2\}$，所以 $A \cap B = \{0, 1, 2, 3\} \cap \{x \mid x \leq 2\} = \{0, 1, 2\}$。因此 $A \cap B = \{0,1,2\}$。
