## 题目
已知函数 $f(x) = \frac{c}{3^x + b} (b, c \in \mathbb{R})$ 的图象关于点(0,1)对称，则 $b + c =$ [选]

## 选项
A．1
B．±1
C．3
D．±3

## 备注

### 我的备注

### AI备注

## 答案
D

## 分析
（无）

## 解析
由题意得 $f(x) + f(-x) = \frac{c}{3^x + b} + \frac{c}{3^{-x} + b} = \frac{c}{3^x + b} + \frac{c \cdot 3^x}{b \cdot 3^x + 1} = \frac{c \cdot 3^{2x} + 2bc \cdot 3^x + c}{b \cdot 3^{2x} + (b^2 + 1)3^x + b} = 2$ 恒成立, 故 $\frac{c}{b} = \frac{2bc}{b^2 + 1} = 2$ , 解得 $b = 1, c = 2$ 或者 $b = -1, c = -2$ , 故 $b + c = \pm 3$ , 应选 D.
