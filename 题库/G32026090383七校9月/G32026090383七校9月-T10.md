## 题目
已知函数 $f(x) = x^{3} - \frac{3}{2}x^{2} + \frac{1}{2}$ ，则下列说法正确的是 [选]

## 选项
A. $f(x)$ 有三个零点
B. 当 $-\frac{1}{2} < x < \frac{1}{2}$ 时， $0 \leq f(2x+1) < \frac{5}{2}$
C. $f\left(\frac{1}{2026}\right)+f\left(\frac{2}{2026}\right)+f\left(\frac{3}{2026}\right)+\cdots+f\left(\frac{2025}{2026}\right)=\frac{2025}{4}$
D. 过点 $\left(0,\frac{1}{2}\right)$ 可以作2条直线与曲线 $y=f(x)$ 相切

## 备注

### 我的备注

### AI备注

## 答案
BCD

## 分析
选项 A，因式分解，重根只计 1 个零点；选项 B，换元法，令 $t=2x+1$ ，确定 t 的取值范围，利用函数单调性和极值求值域；选项 C，利用 $f(x)+f(1-x)$ 为定值，再结合倒序相加法求值；选项 D，设切点 $(x_{0}, f(x_{0}))$ ，写出切线方程，再将点 $\left(0, \frac{1}{2}\right)$ 代入，解出 $x_{0}$ ，即可判断切线数量。

## 解析
对函数求导得 $f'(x)=3x^{2}-3x$ ，令 $f'(x)>0$ ，解得 $x<0$ 或 $x>1$ ，则 $f(x)$ 的单调递增区间为 $(-\infty,0)$ ， $(1,+\infty)$ ;

令 $f'(x) < 0$ ，解得 $0 < x < 1$ ，则 $f(x)$ 的单调递减区间为 $(0,1)$ ，极大值 $f(0) = \frac{1}{2}$ ，极小值

$f (1) = 1 - \frac {3}{2} + \frac {1}{2} = 0.$

选项 A, $f(x)=x^{3}-\frac{3}{2}x^{2}+\frac{1}{2}=\frac{1}{2}(2x^{3}-3x^{2}+1)=\frac{1}{2}(x-1)^{2}(2x+1)$ ，则 $x_{1}=1$ （二重根）， $x_{2}=-\frac{1}{2}$

所以 $f(x)$ 有两个零点，A 错误。

选项B，令 $t = 2x + 1$ ，当 $-\frac{1}{2} < x < \frac{1}{2}$ 时，则 $0 < t < 2$ .当 $t\in (0,1)$ 时， $f(t)$ 单调递减， $f(0) = \frac{1}{2}$

$f (1) = 0$

当 $t \in (1,2)$ 时， $f(t)$ 单调递增， $f(2) = \frac{5}{2}$ ，所以 $t \in (0,2)$ 时， $f(t)_{\min} = f(1) = 0$ ， $f(t) < f(2) = \frac{5}{2}$ ，

故 $0 \leq f(t) < \frac{5}{2}$ ，即 $0 \leq f(2x + 1) < \frac{5}{2}$ ，B正确。

选项C，由题 $f(x) = x^3 -\frac{3}{2} x^2 +\frac{1}{2}$ ，则 $f(1 - x) = (1 - x)^{3} - \frac{3}{2} (1 - x)^{2} + \frac{1}{2} = -x^{3} + \frac{3}{2} x^{2}$ ，所以

$f (x) + f (1 - x) = \left(x ^ {3} - \frac {3}{2} x ^ {2} + \frac {1}{2}\right) + \left(- x ^ {3} + \frac {3}{2} x ^ {2}\right) = \frac {1}{2},$

$\text {令} S = f \left(\frac {1}{2 0 2 6}\right) + f \left(\frac {2}{2 0 2 6}\right) + f \left(\frac {3}{2 0 2 6}\right) + \dots + f \left(\frac {2 0 2 5}{2 0 2 6}\right)$

$S=f\left(\frac{2025}{2026}\right)+f\left(\frac{2024}{2026}\right)+f\left(\frac{2023}{2026}\right)+\cdots+f\left(\frac{1}{2026}\right)$ ，所以 $2S=\frac{1}{2}\times2025$ ，则 $S=\frac{2025}{4}$ ，C正确。
选项 D，设切点 $(x_{0},f(x_{0}))$ ，则切线方程为 $y-f(x_{0})=f'(x_{0})(x-x_{0})$ ，代入 $\left(0,\frac{1}{2}\right)$ ，得 $\frac{1}{2}-f(x_{0})=-x_{0}f'(x_{0})$ ，则 $\frac{1}{2}-\left(x_{0}^{3}-\frac{3}{2}x_{0}^{2}+\frac{1}{2}\right)=-x_{0}\left(3x_{0}^{2}-3x_{0}\right)$ 整理得 $x_{0}^{2}(4x_{0}-3)=0$ ，解得 $x_{0}=0$ （二重根）或 $x_{0}=\frac{3}{4}$ ，故过点 $\left(0,\frac{1}{2}\right)$ 可以作2条直线与曲线 $y=f(x)$ 相切，D正确。
