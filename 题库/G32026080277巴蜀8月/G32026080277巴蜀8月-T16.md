## 题目
16. (本小题满分 15 分)

已知正项数列 $\{a_{n}\}$ 的前 $n$ 项和为 $S_{n}$ ， $\sqrt{4S_{n}} = a_{n} + 1$ .

(1) 求数列 $\{a_{n}\}$ 的通项公式;

(2) 设数列 $\left\{\frac{1}{(a_{n}+1)\sqrt{S_{n+2}}}\right\}$ 的前 n 项和为 $T_{n}(n\in\mathbf{N}^{\circ})$ ，求证： $T_{n}<\frac{3}{8}$ .

## 备注

### 我的备注

### AI备注

## 答案
（1）$a_{n} = 2n - 1.$
（2） 详见解析

## 分析
（无）

## 解析
(1) 解: $n=1, \sqrt{4S_{1}} = a_{1} + 1 \Rightarrow 4a_{1} = a_{1}^{2} + 2a_{1} + 1 \Rightarrow (a_{1}-1)^{2} = 0 \Rightarrow a_{1} = 1,$ ............（2分）<br>$n \geqslant 2, 4S_{n} = a_{n}^{2} + 2a_{n} + 1, 4S_{n-1} = a_{n-1}^{2} + 2a_{n-1} + 1.$ <br>两式相减得: $4a_{n} = a_{n}^{2} - a_{n-1}^{2} + 2a_{n} - 2a_{n-1} \Rightarrow a_{n}^{2} - a_{n-1}^{2} - 2a_{n} - 2a_{n-1} = 0,$ <br>$(a_{n} + a_{n-1}) \cdot (a_{n} - a_{n-1} - 2) = 0.$ <br>又因为 $\{a_{n}\}$ 是正项数列, 则 $a_{n} - a_{n-1} = 2,$ ............（6分)<br>则 $\{a_{n}\}$ 是首项为 1, 公差是 2 得等差数列, 则 $a_{n} = 2n - 1.$ ............（7分)<br>(2) 证明: 由 (1) 得, $S_{n} = \frac{n(1 + 2n - 1)}{2} = n^{2},$ ............（10分）<br>所以 $\frac{1}{(a_{n} + 1)\sqrt{S_{n+2}}} = \frac{1}{2n(n + 2)} = \frac{1}{4}\left(\frac{1}{n} - \frac{1}{n + 2}\right),$ ............（12分）<br>所以 $T_{n} = \frac{1}{4}\left[\left(\frac{1}{1} - \frac{1}{3}\right) + \left(\frac{1}{2} - \frac{1}{4}\right) + \left(\frac{1}{3} - \frac{1}{5}\right) + \dots + \left(\frac{1}{n-1} - \frac{1}{n+1}\right) + \left(\frac{1}{n} - \frac{1}{n+2}\right)\right]$ $= \frac{1}{4}\left(\frac{1}{1} + \frac{1}{2} - \frac{1}{n+1} - \frac{1}{n+2}\right) = \frac{1}{4}\left(\frac{3}{2} - \frac{1}{n+1} - \frac{1}{n+2}\right) = \frac{3}{8} - \frac{1}{4}\left(\frac{1}{n+1} + \frac{1}{n+2}\right) < \frac{3}{8}.$ <br>............（15分）
