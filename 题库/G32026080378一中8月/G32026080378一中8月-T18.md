## 题目
(本小题满分 17 分)

现有 m 张标号为 1, 2, …, m 的质地、大小完全相同的卡片，其中 $m \geqslant 3$ 。甲先随机抽 k 张卡片，记录标号后全部放回，乙再随机抽 k 张卡片，记录标号后全部放回， $k \leqslant \dfrac{m}{2}$ 。设随机变量 X 是甲、乙分别抽到的标号中，有多少种相同标号的数目；随机变量 Y 是甲和乙抽到的标号中，一共多少种标号的数目。如甲抽 1, 2, 3、乙抽 2, 3, 4，有两种相同标号 2, 3，则 X = 2；一共有四种标号 1, 2, 3, 4，则 Y = 4。

(1) 若 m=6, k=3, 求随机变量 X 的分布列;

(2) 求 X 和 Y 的数学期望 $E(X)$ ， $E(Y)$ ;

(3) 求 X 的方差 $D(X)$ .

(若随机变量 $X_{i}(i=1,2,\ldots,m)$ 服从两点分布，则 $X_{i}^{2}, X_{i}X_{j}(i\neq j)$ 也服从两点分布，且有 $E(\sum_{i=1}^{m}X_{i})=\sum_{i=1}^{m}E(X_{i}).$ )

### AI备注


## 答案
（1）分布列是

| X   | 0    | 1    | 2    | 3    |
| --- | ---- | ---- | ---- | ---- |
| P   | $\frac{1}{20}$ | $\frac{9}{20}$ | $\frac{9}{20}$ | $\frac{1}{20}$ |
（2）$E(X) = \dfrac{k^2}{m}$；$E(Y) = \dfrac{2mk - k^2}{m}$
（3）$D(X) = \dfrac{k^2(m-k)^2}{m^2(m-1)}$

## 分析
（无）

## 解析
解：（1）

$P (X = 0) = \dfrac {C _ {3} ^ {3}}{C _ {6} ^ {3}} = \dfrac {1}{2 0}, \quad P (X = 1) = \dfrac {C _ {3} ^ {1} C _ {3} ^ {2}}{C _ {6} ^ {3}} = \dfrac {9}{2 0},$

$P (X = 2) = \dfrac {C _ {3} ^ {2} C _ {3} ^ {1}}{C _ {6} ^ {3}} = \dfrac {9}{2 0}, \quad P (X = 3) = \dfrac {C _ {3} ^ {3}}{C _ {6} ^ {3}} = \dfrac {1}{2 0},$

所以分布列是

| X   | 0    | 1    | 2    | 3    |
| --- | ---- | ---- | ---- | ---- |
| P   | $\frac{1}{20}$ | $\frac{9}{20}$ | $\frac{9}{20}$ | $\frac{1}{20}$ |

……（4分）

（2）如果设甲抽到的标号集合为 $A$ ，乙抽到的标号集合为 $B$ ，<br>那么实际上 $X = |A \cap B|$ ， $Y = |A \cup B|$ ， <br>所以利用容斥原理 $|A \cup B| = |A| + |B| - |A \cap B|$ 得到 $Y = 2k - X$ ， ......... （6分）<br>又观察 <br>$P(X = 0) = \dfrac{C_{m-k}^k}{C_m^k}$ ，<br> $P(X = 1) = \dfrac{C_k^1 C_{m-k}^{k-1}}{C_m^k}$ ， <br>$P(X = 2) = \dfrac{C_k^2 C_{m-k}^{k-2}}{C_m^k}$ <br>…… <br>$P(X = k) = \dfrac{C_k^k C_{m-k}^0}{C_m^k}$ ，<br>看得出来 $X$ 服从超几何分布 $X \sim H(k, k, m)$ ， <br>所以 $E(X) = \dfrac{k^2}{m}$ （也可以用随机变量分解推出期望），……（8分）
进而 $E(Y) = E(2k - X) = 2k - E(X) = \dfrac{2mk - k^2}{m}$ ．……（10分）<br>（3）（方法不唯一，按照期望定义也可以推导） <br>设随机变量 $X_i (i = 1, 2, \ldots, m) = \begin{cases} 1, & \text{第 } i \text{ 张卡片同时被甲、乙抽到} \\ 0, & \text{第 } i \text{ 张卡片没有同时被甲、乙抽到} \end{cases}$ ； <br>则 $X = X_1 + X_2 + \ldots X_m$ ，……（12分）<br> $P(Y_i = 1) = \dfrac{C_{m-1}^{k-1}}{C_m^k} \dfrac{C_{m-1}^{k-1}}{C_m^k} = \dfrac{k^2}{m^2}$ ，<br>第（2）问已知 $E(X) = \dfrac{k^2}{m}$ ， <br>计算 $D(X) = E(X^2) - E^2(X)$ ，只需要算出 $E(X^2)$ 即可， <br>而注意到 $X_i^2 = X_i$ ， <br>$P(X_i X_j = 1) = \dfrac{C_{m-2}^{k-2}}{C_m^k} \dfrac{C_{m-2}^{k-2}}{C_m^k} = \dfrac{k^2(k-1)^2}{m^2(m-1)^2} = E(X_i X_j)$ ，……（14分）<br>所以： $E(X^2) = E((X_1 + \ldots X_m)^2) = E(X_1^2 + X_2^2 + \ldots X_m^2) + 2E(X_1 X_2 + X_1 X_3 + \ldots X_{m-1} X_m)$ $= E(X_1 + X_2 + \ldots + X_m) + 2C_m^2 E(X_i X_j)$ $= E(X) + 2C_m^2 \dfrac{k^2(k-1)^2}{m^2(m-1)^2} = \dfrac{k^2}{m} + 2C_m^2 \dfrac{k^2(k-1)^2}{m^2(m-1)^2} = \dfrac{k^2(m-1 + (k-1)^2)}{m(m-1)}$ ……（16分） <br>所以
方差 $D(X) = E(X^2) - E^2(X) = \dfrac{k^2(m-1 + (k-1)^2)}{m(m-1)} - \dfrac{k^4}{m^2} = \dfrac{k^2(m-k)^2}{m^2(m-1)}$ ．……（17分）
