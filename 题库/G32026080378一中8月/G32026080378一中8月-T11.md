## 题目
已知函数 $f(x) = \dfrac{1}{4^x + 4} - x - 1$ ，则 [选]

## 选项
A．$f(\sqrt{2}) > f(\sqrt{3})$
B．$f(x)$ 的图象是轴对称图形
C．曲线 $y = f(x)$ 不存在斜率为 $-\dfrac{9}{8}$ 的切线
D．$g(x) = f(x) + x + \dfrac{7}{8} + \sin (x - 1)$ 在 $x \in [-5, 7]$ 内所有零点之和为 3

### 我的备注

### AI备注


## 答案
ACD

## 分析
（无）

## 解析
函数 $f(x) = \dfrac{1}{4^x + 4} - x - 1$ 的定义域为 $\mathbf{R}$ ，对于 $\mathbf{A}$ ， $f(x)$ 是 $\mathbf{R}$ 上的单调递减函数， $\mathbf{A}$ 正确；对于 $\mathbf{B}$ ，由 $\mathbf{A}$ 知 $f(x)$ 是 $\mathbf{R}$ 上的单调函数，故 $f(x)$ 的图象不是轴对称图形， $\mathbf{B}$ 错误；对于 $\mathbf{C}$ ， $f'(x) = \dfrac{-(4^x + 4)'}{(4^x + 4)^2} - 1 = -\dfrac{4^x \ln 4}{(4^x + 4)^2} - 1$ ，令 $t = 4^x > 0$ ，则 $\dfrac{t}{(t + 4)^2} = \dfrac{t}{t^2 + 8t + 16} = \dfrac{1}{t + \dfrac{16}{t} + 8} \leqslant \dfrac{1}{2\sqrt{t \times \dfrac{16}{t}} + 8} = \dfrac{1}{16}$ ，当且仅当 $t = 4$ 时等号成立，所以 $-\dfrac{4^x \ln 4}{(4^x + 4)^2} - 1 = -\dfrac{t \ln 4}{(t + 4)^2} - 1 \geqslant -\dfrac{\ln 4}{16} - 1 = -\dfrac{\ln 2}{8} - 1 > -\dfrac{9}{8}$ ，即 $f'(x) > -\dfrac{9}{8}$ ， $C$ 正确；对于 $D$ ， $g(x) = 0 \Leftrightarrow f(x) + x + \dfrac{7}{8} = -\sin (x - 1)$ ，设 $h(x) = f(x) + x + \dfrac{7}{8} = \dfrac{1}{4^x + 4} - \dfrac{1}{8}$ ，则 $h(x) + h(2 - x) = \dfrac{1}{4^x + 4} + \dfrac{1}{4^{2 - x} + 4} - \dfrac{1}{4} = \dfrac{4^{2 - x} + 4 + 4^x + 4}{(4^x + 4)(4^{2 - x} + 4)} - \dfrac{1}{4} = \dfrac{4^{2 - x} + 4^x + 8}{4(4^{2 - x} + 4^x + 8)} - \dfrac{1}{4} = 0$ ，所以 $h(x)$ 关于 (1, 0) 中心对称，且 $h(x) \in \left(-\dfrac{1}{8}, \dfrac{1}{8}\right)$ ，在 $x \in [-5, 7]$ 内， $h(x)$ 与 $y = -\sin (x - 1)$ 共三个交点，所以 $g(x)$ 零点之和等于 $2 + 1 = 3$ ， $D$ 正确，故选 ACD.
