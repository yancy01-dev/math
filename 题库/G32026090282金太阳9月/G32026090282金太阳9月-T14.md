## 题目
已知 $\triangle ABC$ 的内角 $A, B, C$ 的对边分别为 $a, b, c, B = \frac{\pi}{3}, a = 6 - 2c$，且 $\triangle ABC$ 的两条角平分线是 $AD$ 与 $CE$，则当 $AE + CD$ 取得最小值时，$c =$ [填].

## 备注

### 我的备注

### AI备注

## 答案
$\frac{15}{7}$

## 分析
本题考查解三角形的应用，考查数学运算、逻辑推理及直观想象的核心素养.

## 解析
如图，设 $AD$ 与 $CE$ 相交于点 $O$，在 $AC$ 上取点 $F$，使得 $AF = AE$，连接 $OF$，则 $\triangle AEO \cong \triangle AFO$，则 $\angle 3 = \angle 5$。由 $B = \frac{\pi}{3}$，得 $2\angle 1 + 2\angle 2 = \frac{2\pi}{3}$，则 $\angle 5 = \angle 3 = \angle 4 = \angle 1 + \angle 2 = \frac{\pi}{3}$，所以 $\angle 5 + \angle 6 = \pi - (\angle 1 + \angle 2) = \frac{2\pi}{3}$，得 $\angle 6 = \frac{\pi}{3}$。易得 $\triangle CDO \cong \triangle CFO$，则 $CD = CF$，所以 $AE + CD = AF + CF = b$。由余弦定理得 $b ^ {2} = a ^ {2} + c ^ {2} - a c = (6 - 2 c) ^ {2} + c ^ {2}-\left(6-2c\right)c= 7c^2 - 30c + 36 = 7\left(c - \frac{15}{7}\right)^2 + \frac{27}{7}$，当 $c = \frac{15}{7}$ 时，$b$ 取得最小值。
