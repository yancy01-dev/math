## 题目
已知向量 $a, b$ 满足 $a + b = (1, 3), 2a - b = (-4, 3)$，则 [选]

## 选项
A．$a = (-1, 2)$
B．$a // b$
C．$|a| = |b|$
D．$a \perp b$

## 备注

### 我的备注

### AI备注

## 答案
ACD

## 分析
本题考查向量的坐标运算与数量积,考查数学运算的核心素养.

## 解析
将 $a + b = (1, 3)$，$2a - b = (-4, 3)$ 两式相加，得 $3a = (-3, 6)$，即 $a = (-1, 2)$，则 $b = (1, 3) - (-1, 2) = (2, 1)$，所以 $|a| = |b| = \sqrt{5}$，A 正确，C 正确。因为 $a \cdot b = 0$，所以 $a \perp b$，B 错误，D 正确。
