## 题目
函数 $f(x) = \begin{cases} 4\left|\log_4 x\right|, & 0 < x < 4 \\ -\frac{1}{2} x^2 + 7x - 20, & x \geq 4 \end{cases}$ ，若存在实数 $a, b, c, d$ 满足 $f(a) = f(b) = f(c) = f(d)$ ，0 < a < b < c < d，则 $abc(d - 7)$ 的取值范围是 [填].

## 备注

### 我的备注

### AI备注

## 答案
(6, 12)

## 分析
（无）

## 解析
由题可画出函数 $f(x)$ 的图像，根据图象可得 $f(a) = f(b) = f(c) = f(d)$ 有 $ab = 1, c + d = 14$ ，又由于 $f(4) = 2$ 当 $x > 4$ 时， $f(x) = 4$ 的解为 $x = 6$ 或8，故 $c \in (4,6)$ ，所以 $abc(d - 7) = c(7 - c) = -c^2 + 7c \in (6,12)$
