## 题目
已知 $f(x) = -x^{2} + 4$ ，若 $a = f\left(\mathrm{e}^{-\frac{3}{4}}\right)$ ， $b = f\left(\ln\frac{4}{5}\right)$ ， $c = f\left(-\frac{1}{4}\right)$ ，则 a, b, c 的大小关系为 [选]

## 选项
A．c < b < a
B．c < a < b
C．b < c < a
D．a < c < b

## 备注

### 我的备注

### AI备注

## 答案
D

## 分析
（无）

## 解析
因为 $f(x) = -x^{2} + 4$ ，定义域关于原点对称， $f(-x) = f(x)$ ，所以 $f(x)$ 为 R 上的偶函数，且 $f(x)$ 在 $[0, +\infty)$ 上单调递减， $f(x)$ 在 $(-\infty, 0]$ 上单调递增，
又因为 $\ln \frac{4}{5} < 0, -\frac{1}{4} < 0, b = f\left(\ln \frac{4}{5}\right) = f\left(-\ln \frac{4}{5}\right) = f\left(\ln \frac{5}{4}\right), c = f\left(-\frac{1}{4}\right) = f\left(\frac{1}{4}\right)$
又因为 $\mathrm{e}^{-\frac{3}{4}} > \mathrm{e}^{-1} = \frac{1}{\mathrm{e}} > \frac{1}{4}$ , 因为 $\frac{1}{4} = \ln \mathrm{e}^{\frac{1}{4}}, \left(\mathrm{e}^{\frac{1}{4}}\right)^4 = \mathrm{e}, \left(\frac{5}{4}\right)^4 \approx 2.4 < \mathrm{e}$ , 所以 $\mathrm{e}^{\frac{1}{4}} > \frac{5}{4}$ ,
所以 $\ln \mathrm{e}^{\frac{1}{4}} > \ln \frac{5}{4}$ ，即 $\frac{1}{4} > \ln \frac{5}{4}$ ，所以 $\mathrm{e}^{-\frac{3}{4}} > \frac{1}{4} > \ln \frac{5}{4}$ ，所以 $f\left(\mathrm{e}^{-\frac{3}{4}}\right) < f\left(\frac{1}{4}\right) < f\left(\ln \frac{5}{4}\right)$ ，
即 $a < c < b$ . 故选: D.
